Method

How we measured.

  • Apple M1 Pro (8 performance + 2 efficiency cores, 32 GB), macOS 27, warm file cache, two rounds each, the better kept.
  • Wall-clock time for every tool, and every round trip compared with the source. All were identical.
  • Versions: 7-Zip 26.02 (7z -mx9), Zipgeist's 7z at its Best setting, WinRAR (rar -m5, solid), zstd 1.5.7, XZ Utils 5.8.4, and macOS's ditto, which is what Finder's Compress uses. Zipling's numbers are the Arca engine's; the app adds a few milliseconds around it.
  • Every tool waited for an idle machine: the other tools on 30 October 2026, Zipling's locked settings on 31 October, with the load checked before each set.
  • Back-to-back runs vary by about ±10%, so treat small differences as ties.
  • Public and system data only. No personal files were read.

Honesty

Where Zipling is still behind.

  • Max on PDF and PNG folders takes 10.8 s to compress against 7-Zip's 2.8 s, for an archive 52% smaller: re-creating the compression inside PDFs and PNGs is work the other tools skip.
  • The default setting on apps, code and generic data trades size for speed. It is 4–32% larger than 7-Zip Ultra there, but 11–21× faster to compress and 3–17× faster to extract. Max beats 7-Zip on all of them.
  • Fast on generic data ties zstd -3 on compression time and trails Zipgeist's zstd -1 setting by 0.02 s, at a file 12% smaller than theirs.
  • Ultra is 1–2% smaller than Max for 25–50% more compression time, so it stays opt-in.

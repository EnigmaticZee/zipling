The Arca engine

It understands your files.

Most archivers treat everything as anonymous bytes. Arca looks at what each file is, undoes the compression already hiding inside it, and picks the right tool for every kind of data. Then it puts it all back, bit for bit.

Photos, re-encoded losslessly

JPEGs pass through Lepton, which stores the same image in about a quarter less space and rebuilds the original file exactly.

Documents, unpacked

PDFs, PNGs, Office files and ZIPs hide old Deflate compression. Arca reverses it exactly, compresses the raw data with modern codecs, and re-creates the original stream.

Apps, tuned for Apple silicon

ARM64 machine code is filtered so that similar instructions line up, which makes app bundles compress noticeably better.

Duplicates, stored once

Content-defined chunking finds data that repeats across your files and keeps a single copy.

Every core, all the time

Files stream through a parallel pipeline into independent blocks, so packing and extraction keep every core of your Mac busy.

Verified, end to end

Every transform is checked by rebuilding the original before it is kept, and every block carries a BLAKE3 hash that extraction verifies.

FAQ

Questions, answered.

When can I download Zipling?

Not yet. Zipling is in active development. Follow the project on GitHub to see it come together.

What will it cost?

Pricing hasn't been announced yet.

Is it really lossless?

Yes. Every transform is reversible, and Zipling proves it: it rebuilds each original during compression before keeping the smaller form, and checks a BLAKE3 hash of every block when extracting. In the benchmarks every archive was extracted and compared byte for byte with the source.

Can people without Zipling open my archives?

Zipling's own .zlg format is for when you want the smallest archive. When you share with someone who doesn't have Zipling, it will also create standard ZIP and 7z archives that open anywhere.

What is Arca?

Arca is the compression engine inside Zipling, written in Rust for speed and memory safety. It combines format-aware transforms (Lepton for JPEG, preflate for Deflate streams, an ARM64 code filter), deduplication, and modern codecs (Zstandard, LZMA2, PPMd) in parallel blocks.

I found a bug. Where do I report it?

Please open a bug report on GitHub. Include your macOS version and the steps that cause it, and leave out anything personal. Bug reports are public.

Which Macs will it run on?

Macs with Apple silicon.

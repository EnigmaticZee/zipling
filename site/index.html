The Arca engine

It understands your files.

Most archivers treat everything as anonymous bytes. Arca looks at what each file is, undoes the compression already hiding inside it, and picks the right tool for every kind of data. Then it puts it all back, bit for bit.

Photos, re-encoded losslessly

JPEGs pass through Zipling's own coefficient coder, which stores the same image 30% smaller and rebuilds the original file exactly. It checks every photo against the original before keeping it.

Documents and disk images, unpacked

PDFs, PNGs, Office files, ZIPs and disk images hide old compression. Arca reverses it exactly, compresses the raw data with modern codecs, and re-creates the original stream. Disk images come out a quarter smaller at Max.

Apps, tuned for Apple silicon

ARM64 machine code is filtered so that similar instructions line up, which makes app bundles compress noticeably better.

Duplicates, stored once

Content-defined chunking finds data that repeats across your files and keeps a single copy.

Every core, all the time

Files stream through a parallel pipeline into independent blocks, so packing and extraction keep every core of your Mac busy.

Verified, end to end

Every transform is checked by rebuilding the original before it is kept, every block carries a keyed checksum that extraction verifies, and the index a BLAKE3 hash.

The app

See where every byte went.

Zipling is a native Mac app built in SwiftUI. It opens the archives you already have, and for its own it shows, file by file, how much was saved and how.

  • Opens ZIP, 7z, RAR, TAR, DMG, ISO, StuffIt and classic Mac formats, split and password-protected archives
  • Fixes garbled names from old Windows and Japanese or Chinese ZIPs
  • Archives inside archives open in place, and search looks inside them too
  • Quick Look and drag out any file without extracting the rest
  • Makes Zipling, ZIP, 7z and TAR archives, encrypted and split, and edits them in place
  • Extract Here keeps things tidy, in the background, with progress on the Dock
  • Converts any archive to Zipling, ZIP or 7z, and shows the new size and time before you start
  • Compress fast now: Zipling shrinks it to Max later, while your Mac is idle and plugged in
  • Recovery files repair a damaged archive, byte for byte
  • Lives in Finder: Quick Look for archives, right-click menu, menu-bar drop zone
  • Works with Shortcuts, AppleScript and Folder Actions, and Spotlight finds archives by the files inside
  • Safe extraction: nothing escapes the folder, and downloaded files stay marked for Gatekeeper

FAQ

Questions, answered.

When can I download Zipling?

Not yet. Zipling is in active development. Follow the project on GitHub to see it come together.

What will it cost?

Pricing hasn't been announced yet.

Is it really lossless?

Yes. Every transform is reversible, and Zipling proves it: it rebuilds each original during compression before keeping the smaller form, and checks a keyed checksum of every block and a BLAKE3 hash of the index when extracting. In the benchmarks every archive was extracted and compared byte for byte with the source.

Which formats can Zipling open?

ZIP, 7z, RAR, TAR (including .tar.gz, .tar.bz2, .tar.xz and .tar.zst), DMG, ISO, WIM, archives split into parts, and password-protected archives, plus dozens more through the 7-Zip engine. Classic Mac formats such as StuffIt, BinHex and MacBinary open through The Unarchiver's engine, which also repairs file names written in old Windows, Japanese, Chinese and Korean encodings.

Can people without Zipling open my archives?

Zipling's own .zlg format is for when you want the smallest archive. When you share with someone who doesn't have Zipling, it creates standard ZIP, 7z and TAR archives that open anywhere, with AES-256 encryption and split parts if you want them.

Can Zipling make the archives I already have smaller?

Yes. Convert turns any archive Zipling opens into a Zipling archive, or into a tighter ZIP or 7z that still opens anywhere. It shows the new size and how long it will take before you start, checks the new archive once it's written, and only then moves the old one to the Trash if you ask it to.

What if an archive gets damaged?

Give it a recovery file. Zipling saves repair data next to any archive, at 5, 10 or 20% of its size, and if the archive is later damaged by a failing disk or a broken download, it rebuilds the damaged parts exactly, byte for byte. If more is damaged than the recovery file can cover, Zipling tells you instead of guessing. It works for any archive, not just Zipling's own.

What is Arca?

Arca is the compression engine inside Zipling, written in Rust for speed and memory safety. It combines format-aware transforms (its own JPEG coefficient coder, preflate for Deflate streams, disk-image expansion, ARM64 and x86 code filters), deduplication, and modern codecs (Zstandard, LZMA2, bsc's BWT coder, PPMd) in parallel blocks, with a different mix at each level.

I found a bug. Where do I report it?

Please open a bug report on GitHub. Include your macOS version and the steps that cause it, and leave out anything personal. Bug reports are public.

Which Macs will it run on?

Macs with Apple silicon.
